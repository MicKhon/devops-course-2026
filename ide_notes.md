# Git в VS Code vs терминал

## Что удобнее в VS Code

1. Визуальный diff: сразу видно, какая строка добавлена или удалена, без ручного чтения `git diff`.
2. Точечный staging: можно отправить в индекс не весь файл, а отдельные hunks — это удобно, когда в одном файле смешаны две правки.
3. GitLens (blame): над строкой видно, кто и когда её менял. Это быстрее, чем каждый раз вызывать `git blame`.

## Что удобнее в терминале

Интерактивный rebase, cherry-pick и работа на удалённом сервере. На сервере нет GUI, а `git rebase -i` и разбор нестандартной истории в терминале прозрачнее, чем через кнопки IDE.
