# Мой пет-проект

Идея: Telegram-бот `deploystatus`, который по расписанию проверяет HTTP-healthcheck учебных и пет-сервисов и присылает алерт, если сервис недоступен дольше заданного порога. Дополнительно — команда `/status` для ручной проверки.

Стек: Python 3.12 / python-telegram-bot / httpx / Docker / GitHub Actions

Цель: научиться упаковывать сервис в Docker, настраивать CI и выкатывать его на VPS без ручных SSH-команд каждый раз
