# Цели на семестр

1. Научиться собирать и запускать сервисы в Docker и Docker Compose так, чтобы окружение воспроизводилось на любой машине, а не только «у меня локально работает».
2. Настроить CI/CD на GitHub Actions: проверка кода, тесты и сборка образа на каждый Pull Request.
3. Освоить Linux/Bash и базовый IaC (Ansible или Terraform) до уровня, чтобы поднять простой сервис на виртуальной машине без ручной настройки «по памятке».
